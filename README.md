**CO3 Portal** connects your AI assistant to the data you already see in the
[CO3 portal](https://co3.io). You sign in with your CO3 portal account, and the assistant reads
your company's trackings and assets to answer questions. A set of skills teaches it how to read
CO3's figures the way your team would.

It is **read-only**. The assistant sees exactly what you see in the CO3 portal, in the company
you choose, and it cannot change anything.

## What you can ask

| Area | For example |
| --- | --- |
| **Deliveries** | *Where is tracking ORDER-1042 and will it be late?* · *Which of today's deliveries are running late?* |
| **Waiting and stops** | *How long did PO12345 wait at the depot yesterday?* · *Check this waiting-time invoice against what the truck did.* |
| **Driver hours** | *How long until the driver of PO12345 needs a break?* |
| **Cold chain** | *Did the load on ORDER-1042 stay in range the whole way?* · *Which reefers are too warm right now?* |
| **Emissions** | *What was the CO₂ of tracking ORDER-1042, and by which method?* |
| **Fuel** | *How much fuel did PO12345 use this week?* |
| **Carriers and assets** | *Which carriers share assets with us?* · *How many assets do we monitor permanently?* |

Ask in your own language. Answers come back in the language you write in.

## Before you start

- A **CO3 portal account**. You sign in with it when your assistant first connects.
- An AI assistant from the list below.
- Some answers depend on what your company has in CO3. Cold chain answers need Cold Chain, and
  CO₂ answers need CO₂ reporting. Where a feature is not enabled, the assistant says so.

The connection address, for any assistant that asks for one, is:

```
https://mcp.co3.tech/portal-mcp
```

## Install

### Claude (claude.ai and Claude Desktop)

1. Open **Customize › Plugins › Add marketplace** and enter `CO3-Tech/co3-portal-mcp`.
2. Install **CO3 Portal**.
3. The first time you ask about CO3, sign in with your CO3 portal account.

Prefer to add only the connection? Open **Customize › Connectors › Add custom connector** and
paste the connection address. On Team and Enterprise plans, an owner adds it once under
**Organization settings › Connectors**, and each member then connects with their own account.

### Claude Code

```bash
claude plugin marketplace add CO3-Tech/co3-portal-mcp
claude plugin install co3-portal@co3-portal
```

Then run `/mcp` and sign in to **co3-portal**.

### ChatGPT

Add a custom connector with the connection address. Custom connectors depend on your ChatGPT
plan; on Business and Enterprise plans a workspace admin may need to allow them first. Sign in
with your CO3 portal account when ChatGPT connects.

### OpenAI Codex

```bash
codex plugin marketplace add CO3-Tech/co3-portal-mcp
```

Install **co3-portal** from `/plugins`, then sign in:

```bash
codex mcp login co3-portal
```

To add only the connection:

```bash
codex mcp add co3-portal --url https://mcp.co3.tech/portal-mcp
codex mcp login co3-portal
```

### Mistral Le Chat

An admin adds an MCP connector with the connection address under **Connectors**. Members then
connect with their own CO3 portal account.

### Any other MCP client

Add a **remote MCP server** that uses the **Streamable HTTP** transport, at the connection
address. Sign-in uses OAuth with dynamic client registration, so no client id or secret is
needed. You sign in with your CO3 portal account.

### Skills without the plugin

Each skill is attached to every [release](https://github.com/CO3-Tech/co3-portal-mcp/releases/latest)
as a zip file.
- **claude.ai:** upload a skill under **Customize › Skills** and add the connection as a
  custom connector. Skills need code execution switched on.
- **Codex:** copy the skill folders into `~/.agents/skills`.

### Not supported yet

- **Microsoft 365 Copilot declarative agents** need a client secret issued at registration,
  which CO3 Portal does not issue. Use **Microsoft Copilot Studio** with the connection
  address instead.
- **GitHub Copilot coding agent** does not support remote servers that sign in with OAuth.

## Skills

| Skill | What it does |
| --- | --- |
| **delivery-status** | Where a delivery is and whether it will be late: missed windows first, then CO3's ETA and when it was calculated. |
| **dwell-and-detention** | How long an asset stood still, when and where. Use it to check waiting-time claims against what the asset did. |
| **driver-hours-check** | How much driving time is left before a break, today and this week, as CO3 computes it. |
| **cold-chain-check** | Which reefers are off their set point now, and which trackings need cold chain attention. |
| **cold-chain-journey** | Whether a load kept its temperature over a journey, as evidence: excursions and the hours CO3 could grade. |
| **cold-chain-analysis** | Patterns across a cold chain export from the CO3 portal: where hours out of spec concentrate. |
| **emissions-report** | CO₂e of a tracking, from CO3's report, with its method and scope. |
| **trip-efficiency** | Fuel used, distance and consumption of a truck over a period. |
| **carrier-roster** | Your carriers and their consents, and how many assets you can see in each portal view. |

Your assistant chooses the skill. You only ask the question.

## How CO3 answers

- **Figures are CO3's.** ETAs, driver hours, temperatures and CO₂ come from CO3 as they are in
  the portal. The assistant does not estimate its own.
- **Some questions have no answer in the data, and the assistant says so.** It will not tell a
  driver they may keep driving, declare a load safe, turn fuel into CO₂, or give a reason for
  a delay that CO3 did not record.
- **One company at a time.** If you work for several companies, the assistant asks which one
  before it reads anything.

## Privacy and security

- You sign in with your own CO3 portal account. Access follows your portal permissions, and
  ends when they do.
- This repository holds no credentials. Your assistant registers itself with CO3 and receives
  a token after you sign in.
- CO3 processes your data as described in the
  [privacy policy](https://co3.io/privacy-policy) and
  [terms and conditions](https://co3.io/terms-and-conditions).
- To report a security issue, see [SECURITY.md](SECURITY.md).
